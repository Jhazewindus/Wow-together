# Durotar player-facing context text audit — 13 October 2026

This audit follows the text-only Durotar cleanup prompt on `guides/coverage` at addon 0.8.66. It preserves quest facts, wording needed for correct completion, guide order, prerequisites and automatic progress. Previous Durotar fact research and evidence remain in [`../durotar-2026-10-08/README.md`](../durotar-2026-10-08/README.md) and its `refresh-0.8.60` report.

## What creates the visible text

- `WowTogether/GuideText.lua` composes objective instructions, `GuideStepHint`, reason text and locations into the guide-step tooltip.
- `WowTogether/GuideReasons.lua` creates reasons from route and quest state. Its ordinary objective fallback says that a target/item is needed to finish the quest. `GuideVisibleReason` also appends a step hint for objective steps.
- `WowTogether/Navigation.lua` uses destination purpose in navigation context; `WowTogether/StandaloneArrow.lua` displays it with a “Why:” prefix. `WowTogether/GuideQuestList.lua` and arrow/map tooltips use the shared step-description function.

The Durotar catalogue has 54 direct zone records and zero player-facing entries in `travelReason`, `description`, `forPlayer` or `confirmationReason`. The two applicable guides likewise contain zero zone-authored optional context fields. Existing instructions and labels are actionable quest data, so changing them would risk losing useful facts. This cleanup therefore kept 0, rewrote 0 and removed 0 Durotar-authored flavor strings; all 92 objective action steps were preserved.

The problem is generated by shared rendering. For example, the current Lazy Peons tooltip contains:

```text
Use Foreman's Blackjack on 5 × Lazy Peon
Use the item on 5 targets in total.
Required for Thazz'ril's Pick later in this guide; finish and turn in Lazy Peons first.
```

The prerequisite context earns its place; the middle line simply repeats the action. Securing the Lines currently shows:

```text
Kill 12 × Dustwind Savage
Finish this quest objective in the marked area.
Dustwind Savage is needed to finish Securing the Lines.
```

For an ordinary objective, both generated context lines repeat the action's purpose. The actual concise after-state should be just `Kill 12 × Dustwind Savage`; the Lazy Peons case should keep its genuinely useful prerequisite context while dropping the duplicate generic hint. That shared rendering change is proposed for coordination and was not implemented here, as requested.

## Coordination item

The main developer should review the shared context policy before implementation: retain the action once, and display optional context only when it explains a useful prerequisite, level exception, travel decision, danger or preparation need. Ordinary “this target is needed for this quest” and generic “finish this objective in the marked area” text should not appear beside every actionable instruction. This behavior affects all zones and cannot be corrected through a Durotar-only data edit.

Native checks remain useful for fresh/mid-zone guide display, Scan/reload/re-entry, class setting, prerequisite hand-ins, escort recovery and actual route use. No quest facts or guide behavior changed in this audit.
