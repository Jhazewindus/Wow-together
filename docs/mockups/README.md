Open any `.html` file in a browser. These are the visual reference for
CODEX_APP_REDESIGN.md and CODEX_UI_PRESENTATION.md:

| file | screen |
|---|---|
| Main.html | HUD step card with a chip inside the card |
| HudGlance.html | HUD Glance mode (current + next two) |
| HudTravel.html | HUD travel leg borrowing the card |
| HubPlay.html | Hub — Play tab |
| HubGroup.html | Hub — Group tab |
| HubBrowse.html | Hub — Browse tab |
| HubSettings.html | Hub — Settings tab |
| HubGold.html | Hub — Gold tab (module, later) |

Spacing, hierarchy and content are the instruction; exact fonts, corners
and colours follow the in-game notes in CODEX_APP_REDESIGN.md. Every UI PR
pastes an in-game screenshot next to the matching board.
